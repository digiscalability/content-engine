# P1.6 Film Drive Indexer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution for this slice is native.

**Goal:** `ce index-films` indexes every film on a registered film drive in place and read-only, and resumes where it stopped (SRD §8.2). Per film it stores:
- the transcript (sidecar or embedded subtitles first, else Whisper);
- scene cuts, with one keyframe thumbnail per scene;
- text embeddings of the transcript in chunks.

**Architecture:**
- `engine/library/volumes.py`: finds mounted volumes by serial and label (Windows `GetVolumeInformationW`, behind a probe that tests replace).
- `engine/library/subtitles.py`: parses SRT and VTT.
- `engine/library/film_index.py`: discovery, the fingerprint and the per-film steps. Each step commits in its own transaction, and a `film_index` row records which steps are done and the last error.
- `sync_sources()` mirrors `sources.yaml` into the `sources` table.
- The CLI, a wrapper script and a dry-run task entry.

**Spec:** `docs/SRD.md` §8.2, §6.3 (FR-UND-1, 2, 3), §13 (00:00–06:00 when a drive is connected), FR-SRC-1..3, NFR-5, NFR-6.

## Global Constraints

- **Nothing is written to the drive and no film is copied into `media/`.** Only the DB, keyframe JPEGs and short-lived temp audio under `media/` are written.
- Drive letters change: a source matches only on volume serial and label. Asset paths are stored relative to the volume.
- Whisper holds the GPU lock per film, not for the whole night, so the 04:00 daily render can interleave (NFR-6).
- Disk below `disk.stop_free_gb` stops the run (NFR-5). `--until HH:MM` stops it from starting a new step after the deadline.
- CLIP keyframe embeddings and sqlite-vec stay with P0.6b. Text embeddings are stored as float32 blobs for now.

## Tasks

1. Volumes and sources:
   - `sync_sources(conn, config)`;
   - `Volume(root, serial, label)` and `mounted_volumes()`;
   - `find_volume(source, volumes)`, which normalises the serial and compares the label without regard to case;
   - `ce index-films --volumes` lists the connected volumes, so Abbas can write the source entry.
2. Discovery and fingerprint:
   - video files under the drive (or its `path` subfolder);
   - `film_fingerprint()` is the sha256 of the size plus three 4 MiB samples (start, middle, end);
   - the asset is a `film_reference` row with its relative path, probe metadata, and an attribution parsed from "Title (Year)".
3. Transcript:
   - sidecar `.srt`/`.vtt`, then an embedded text subtitle stream, then Whisper large-v3 on 16 kHz audio under the GPU lock;
   - stored in `transcripts` with the model naming the route.
4. Scenes and keyframes:
   - ffmpeg scene cuts on a 320 px proxy, scenes of at least 1 s;
   - a 320 px JPEG at each scene's midpoint under `media/index/films/<asset_id>/`.
5. Chunks:
   - about 30 s windows of the transcript, embedded with the configured embedder;
   - stored in `transcript_chunks` (migration 0004, with the `film_index` status table).
6. The run:
   - `index_films()` walks each source and film and does the steps not yet done, recording errors and skipping a broken film until `--retry-failed`;
   - deadline and disk checks between steps;
   - `ce index-films [--until 06:00] [--retry-failed]`;
   - `scripts/run_index_films.ps1` and a `ContentEngine-IndexFilms` 00:00 entry in `register-tasks.ps1`, still a dry run;
   - ADR 0020; verify; record.

## Review Focus

1. Indexing must never write to the drive → `test_indexing_never_writes_to_the_drive`.
2. A run stopped mid-film must resume without duplicate rows → `test_a_rerun_resumes_and_adds_nothing_twice`.
3. A drive on a new letter must still be found, and a lookalike volume must not → `test_the_drive_is_found_by_serial_and_label_not_letter`.
4. A broken film must not block the rest or be retried every night → `test_a_broken_film_is_recorded_and_skipped`.
5. The run must not start new work after the deadline → `test_the_run_stops_at_the_deadline`.
