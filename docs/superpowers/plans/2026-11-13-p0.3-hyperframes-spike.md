# P0.3 HyperFrames Windows Spike Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution for this slice is native.

**Goal:** Prove HyperFrames renders a 5 s caption overlay with alpha on this Windows PC and that ffmpeg composites it over a test clip into a spec MP4; record the outcome in ADR 0001 (C9: Remotion if it fails).

**Architecture:** A portrait HyperFrames composition with a transparent root (`hyperframes/captions-spike/`) is rendered by `HyperFramesRenderer`, which implements the `OverlayRenderer` interface (§7.2) by calling the pinned CLI with telemetry, update checks and skill installs off. `engine/produce/ffmpeg.py` composites the alpha overlay over a base clip (NVENC H.264, AAC 48 kHz, metadata stripped) and probes the result. A `golden` test runs the whole chain on a generated clip.

**Tech Stack:** HyperFrames CLI `hyperframes@0.9.40` (npm, heygen-com, Apache-2.0) via `npx`, its cached `chrome-headless-shell` 148, FFmpeg 8.0.1 with `h264_nvenc`.

**Spec:** `docs/SRD.md` §7.2, §18.2 P0.3, C9, FR-PRD-5, NFR-8, NFR-9. Build rules: `docs/BUILD_PROMPT.md`.

**Requirement ids touched:** §7.2 (HyperFrames overlay to alpha video, composited by ffmpeg; `OverlayRenderer` slot; "confirms local renders make no metered calls"), C9 (spike, Remotion fallback), FR-PRD-5 (1080×1920 H.264 NVENC 30 fps, AAC 48 kHz, metadata stripped; loudness is P0.4), NFR-8 (renderer and ffmpeg behind injectable runners with fakes; real render under `golden`), NFR-9 (fixture clip generated, not real footage).

## Global Constraints

- HyperFrames pinned to `0.9.40` in one place (`engine/produce/overlay.py`); every call sets `HYPERFRAMES_NO_TELEMETRY=1`, `HYPERFRAMES_NO_UPDATE_CHECK=1`, `HYPERFRAMES_SKIP_SKILLS=1` (no data off the PC, no changes to `~/.claude/skills`).
- No HeyGen sign-in, `cloud`, `lambda`, `cloudrun`, `publish`, `tts` or `feedback` commands.
- Output spec (FR-PRD-5): 1080×1920, H.264 (`h264_nvenc`), 30 fps, `yuv420p`, AAC 48 kHz, `-map_metadata -1`.
- Fixture media is generated by ffmpeg (`testsrc2`, `sine`), never real footage.

## Review Focus

1. The overlay's transparent areas must stay transparent after compositing, not turn black: measured by comparing the composite and base clip in a region with no captions. → Task 3 `test_spike_composite_keeps_background_where_overlay_is_clear`.
2. A VP9 WebM's alpha is dropped by ffmpeg's native decoder unless `libvpx-vp9` decodes it; the composite must use a format whose alpha ffmpeg reads by default. → Task 1 probe of the overlay's pixel format, ADR 0001.
3. `npx` on Windows is `npx.cmd`; the renderer must resolve it, and a missing Node gives a clear error. → Task 2 `test_missing_npx_is_reported`.
4. A failed render surfaces the CLI's error text, not a bare exit code. → Task 2 `test_render_failure_carries_cli_output`.
5. A base clip without audio still composites (later format C posts mux VO separately). → Task 2 `test_composite_command_maps_optional_audio`.
