# P0.4 Edit Plan and ffmpeg Renderer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution for this slice is native.

**Goal:** A pydantic edit plan (§7.1) that fully determines a render, and an ffmpeg renderer that turns it into a format C MP4 (FR-PRD-5): trims, crop, cover reframe, speed, freeze, eased zoom, LUT grade, alpha overlays, VO with sidechain-ducked music and SFX, two-pass loudnorm, NVENC encode, metadata stripped; pinned by a golden test.

**Architecture:** `engine/produce/editplan.py` holds the models and timing maths. `engine/produce/render_ffmpeg.py` builds two filter graphs as text (pure functions, unit-tested): an audio mix rendered to `mix.wav`, then the final graph (video chain + `loudnorm` pass 2 on the mix). ffmpeg reads each graph from a file (`-/filter_complex <file>`, ffmpeg 7+), so long timelines never hit the Windows command-line cap. Assets, overlays and the LUT reach the renderer as resolved paths (`RenderSources`); the DB and look lookups arrive in later slices.

**Tech Stack:** FFmpeg 8.0.1 (`lut3d`, `zoompan`, `loop`, `sidechaincompress`, `loudnorm`, `ebur128`, `h264_nvenc`, `prores_ks`), pydantic 2.

**Spec:** `docs/SRD.md` §7.1, §7.2, §7.5, §4.1 (format C), FR-PRD-5, NFR-8, NFR-9.

**Requirement ids touched:** §7.1 (edit plan: timeline, audio, overlays, captions, look), §7.2 (ffmpeg duties except RNNoise and FCPXML/OTIO), §7.5 (golden: duration, resolution, loudness, frame hashes within tolerance), FR-PRD-5 (1080×1920 H.264 NVENC 30 fps, AAC 48 kHz, −14 LUFS / −1 dBTP from `engine.yaml`, metadata stripped), NFR-8 (renderer behind injectable runner; real ffmpeg only under `golden`), NFR-9 (all fixtures generated).

**Out of scope, named so they are not lost:** RNNoise on real-you clips (P2.7, needs an `arnndn` model file), subject-tracking reframe (§7.3, P2.6), `render_report.json` and FCPXML/OTIO exports (FR-PRD-7, C7: no slice names them; proposed for P0.7), crossfade transitions, look-constrained caption overrides (P0.8).

## Global Constraints

- Output: 1080×1920, 30 fps, `yuv420p`, `h264_nvenc`, AAC 48 kHz; loudness −14 LUFS integrated, −1 dBTP (FR-PRD-5, `engine.yaml` `render`/`loudness`).
- Edit plan JSON keeps the SRD's names: shots use `"in"` and `"out"` (Python `in_s`/`out_s` with aliases).
- Shot audio is never used in P0.4: format C's speech is the VO track (the avatar is lip-synced to the same WAV).
- Graphics are composited after the LUT, so the grade never tints captions or cards.

## Review Focus

1. A plan whose voice segments overlap, or whose overlays run past the end, is rejected at validation, not rendered with garbage. → Task 1 `test_overlapping_voice_rejected`, `test_overlay_past_end_rejected`.
2. A LUT or source path with a drive colon or spaces (`C:\Users\...`) must survive filter-graph escaping. → Task 2 `test_filter_path_escapes_windows_paths`; the golden run uses real Windows temp paths.
3. A plan with no audio at all (no VO, music or SFX) still renders, with silence and no loudnorm on `-inf`. → Task 2 `test_audio_graph_without_any_audio_is_silence`, Task 3 `test_silent_mix_skips_loudnorm`.
4. Ducking depth is what the plan asks for, not whatever a compressor happens to do. → Task 2 `test_duck_floor_gain_math`; golden measures it.
5. Rounding: shot frame counts must add up to the plan duration ±1 frame. → golden duration check.

### Task 2: filter graph builders

**Files:** Create `engine/produce/render_ffmpeg.py`, `tests/unit/test_render_ffmpeg.py`

**Interfaces:**
- `@dataclass(frozen=True) class RenderSettings: width=1080, height=1920, fps=30, sample_rate=48000, lufs=-14.0, true_peak=-1.0, encoder="h264_nvenc"` and `from_engine(engine: EngineConfig)`.
- `@dataclass(frozen=True) class RenderSources: assets: Mapping[int, Path]; overlays: Mapping[str, Path] = {}; captions: Path | None = None; lut: Path | None = None`.
- `filter_path(path: Path) -> str` (forward slashes, `\:` for the drive colon, `\'` for quotes, wrapped in `'…'`).
- `duck_floor_gain(duck_db: float) -> float` = `1 / (10 ** (duck_db / 20) - 1)`: the dry-music share that sets the ducked level to exactly `-duck_db` dB after normalising by `1 + k`.
- `shot_chain(shot, input_index, label, settings) -> str`: `trim`, `setpts`, crop, speed (`setpts=PTS/s`), `fps`, cover (`scale=…:force_original_aspect_ratio=increase,crop=W:H,setsar=1`), freeze (`loop=loop=n:size=1:start=f,setpts=N/FPS/TB`), zoom (`scale=2W:2H,zoompan=z='…':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=1:s=WxH:fps=FPS`), `format=yuv420p`.
- `video_graph(plan, sources, settings) -> tuple[str, list[Path]]`: shot chains, `concat`, `lut3d` if a LUT, then each placed overlay and the captions (`setpts=PTS-STARTPTS+S/TB`, `overlay=0:0:format=auto:eof_action=pass:enable='between(t,S,E)'`), ending `[vout]`; returns the graph and the ordered input files.
- `audio_graph(plan, sources, settings) -> tuple[str, list[tuple[list[str], Path]]]`: per-input options (music gets `-stream_loop -1`), VO segments `atrim`/`adelay`, music `volume` then ducking (`asplit`; `sidechaincompress=threshold=0.001:ratio=20:attack=20:release=300` keyed by the VO; dry copy at `k`; `amix=normalize=0` then `volume=1/(1+k)`), SFX `adelay`/`volume`, all summed, `apad`/`atrim` to the plan duration, ending `[aout]`; with no audio, `anullsrc`.
- `parse_loudnorm(stderr: str) -> dict[str, str]` (the last JSON block); `loudnorm_filter(measured, settings) -> str | None` (`None` when `input_i` is `-inf`).

- [ ] Tests first: `test_filter_path_escapes_windows_paths`; `test_duck_floor_gain_math` (12 dB → k ≈ 0.3346; ducked level −12 dB); `test_shot_chain_trims_fits_and_formats`; `test_shot_chain_speed_freeze_zoom`; `test_video_graph_grades_before_overlays`; `test_video_graph_places_annotations_and_captions`; `test_audio_graph_ducks_music_under_voice`; `test_audio_graph_loops_music_input`; `test_audio_graph_without_any_audio_is_silence`; `test_parse_loudnorm`; `test_loudnorm_filter_is_linear_pass_two`; `test_silent_mix_skips_loudnorm`. Red, implement, green, commit `feat(produce): build ffmpeg filter graphs from an edit plan`.
