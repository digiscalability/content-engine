# P0.6b.2 Stock Fetch and Music Pool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pexels stock fetch behind an interface with a fake and a licence record per clip, plus music pool import, both feeding `search_library`.

**Architecture:** `StockProvider` (Pexels on httpx, `FakeStock`) is called only by a nightly Python job, `ce stock fetch`, whose only input is `stock_requests` rows that `search_library` queues when a scriptwriter's beat query (with its `brief_id`) finds nothing strong. Each fetched clip is registered with an `asset_licences` row and indexed by the existing ingest. Music pools are `kind: library` sources with a path; `ce ingest` imports their audio files as `tracks` (tempo, energy, tags) with a licence record each, and `search_library` gains `kind: "music"`.

**Tech Stack:** Python 3.11, sqlite + sqlite-vec, httpx (MockTransport in tests), ffmpeg/ffprobe, pydantic, typer, pytest.

**Spec:** `docs/SRD.md` (FR-ING-5, FR-ING-6, FR-SRC-2, FR-SRC-3, FR-PRD-4, §5.4, §8.1, §8.3, §11, §13, NFR-1, NFR-5, NFR-7, NFR-8, NFR-9, C14, GR-7); `docs/adr/0022-own-footage-library.md`; `docs/PROGRESS.md` › P0.6b.2.

## Global Constraints

- Done when: the Pexels contract tests pass on the fake, and imported tracks come back from `search_library`.
- No real Pexels call: no `PEXELS_API_KEY` exists. A real-call test carries the `live` marker.
- Every external call behind an interface with a fake (NFR-8); keys only from `engine.settings.Settings`, never in messages, logs or the DB (NFR-7).
- Fixture clips and tracks are generated by the tests (NFR-9); nothing under `media/` is committed.
- New sources come only from `config/sources.yaml`; no code writes it (FR-SRC-3).
- Schema changes are a new migration file, `0006_stock_music.sql` (ADR 0006).
- `uv run pytest`, `-m golden`, `-m model`, `ruff check`, `ruff format --check` and `ce doctor` (0 fail) pass at the end.

## Review Focus

- A Pexels result whose files are all landscape or below 1080 wide is skipped, never upscaled (Task 2 `test_pick_file_*`).
- HTTP 429 mid-run stops the fetch and leaves the remaining requests pending (Task 4 `test_rate_limit_stops_and_keeps_requests`).
- A file dropped by hand into the stock folder is indexed but never searchable, having no licence record (Task 4 `test_a_hand_dropped_stock_file_is_not_searchable`).
- The engine's own voice WAVs (audio assets) never come back as music (Task 5 `test_voice_wavs_are_not_music`).
- A track that cannot be decoded is recorded, the run goes on, and it is skipped until `--retry-failed` (Task 5 `test_a_broken_track_is_recorded_and_skipped`).

- `StockError(RuntimeError)`, `StockRateLimited(StockError)`.

### Task 5: Music pool import and music search

**Files:**
- Create: `engine/library/music.py`, `tests/unit/test_music.py`
- Modify: `tests/unit/library_fixtures.py` (`make_track(path, bpm, seconds, title, artist)`), `engine/style/look.py` (`energy_band(tempo) -> Literal["low","medium","high"]`, used by `propose.py`), `engine/library/search.py` (`search_music`), `engine/agents/tools.py` (`kind`, `tempo_bpm`, `energy`), `engine/cli.py` (`ce ingest` imports music first; music needs no models)

**Interfaces:**
- `music_sources(config) -> list[SourceConfig]`: library sources with a path.
- `MusicImporter(conn, config, run: Runner = run_command, hasher=file_sha256).run(source_id=None, retry_failed=False) -> MusicReport` (`tracks: list[TrackResult]`, `missing: list[str]`). Audio suffixes `.mp3 .m4a .aac .wav .flac .ogg .opus`. Per file: register as `audio`, people `none`; title and artist from tags (else the file stem); tempo from the first 90 s at 22,050 Hz mono by `tempo_bpm`; energy by `energy_band`; a licence row from the source (licence URL, `rights_proof` as terms, attribution, artist as creator). Each scan re-copies the source's licence onto its tracks.
- `search_music(conn, tiers, query, today, limit, tempo: tuple[int, int] | None, energy: str | None) -> dict`: eligible imported tracks only, ordered by energy match, distance outside the tempo range, query words in title or artist, id.
- `SearchInput.kind: Literal["footage", "music"] = "footage"`, `tempo_bpm: tuple[int, int] | None`, `energy: Literal["low","medium","high"] | None`.
