# P1.3 Rest of the QA Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution for this slice is native.

**Goal:** Finish the QA gate:
- **FR-QA-3 self-dedupe.** Script cosine above 0.90 against the identity's own last 50 posts is a hard fail.
- **FR-QA-4 spec.** Resolution, duration, fps, loudness, caption safe zones and caption coverage of at least 95% are checked.
- **FR-QA-7 review.** The reviewer fills a GR-3 checklist, and a pass needs two of its four.

**Architecture:**
- The deterministic checks run in `run_qa_checks`, beside rights, disclosure, banned terms and claims. The new checks are `engine/qa/dedupe.py` and `engine/qa/spec.py`, both pure functions over rows and the render report.
- Embeddings live in `engine/library/embeddings.py`:
  - an `Embedder` protocol;
  - `BgeSmall` (onnxruntime and tokenizers, with the model from the Hugging Face cache at a pinned revision);
  - `FakeEmbedder` (hashed bag of words).
- The caption box is measured from the alpha overlay at render time (ffmpeg `alphaextract,bbox`) and stored in the render report.

**Tech stack:** numpy, onnxruntime, tokenizers and huggingface-hub. All are installed already and become direct dependencies. Model: `BAAI/bge-small-en-v1.5` at revision `5c38ec7c`, downloaded with Abbas's OK on 2026-11-13.

**Spec:** `docs/SRD.md` §6.7 (FR-QA-3, 4, 7), C12, GR-3, §11 `renders.script_embedding`.

## Global Constraints

- Thresholds come from `engine.yaml`:
  - `qa.self_dedupe` (0.90 over the last 50 posts);
  - `qa.caption_coverage_min` (0.95);
  - new: `qa.loudness_tolerance_lu` (1.0) and `qa.safe_zones` per platform.
- Safe zones are third-party estimates, not platform specs; they live in config for Abbas to edit.
- Checks run once per render and their verdicts are final (ADR 0013). A render made before this slice gets only its missing checks.
- No network at run time: the embedder loads with `local_files_only`, and a missing model is an error that names `ce models fetch`.

## Tasks

1. Embedder: protocol, `BgeSmall`, `FakeEmbedder`, `ce models fetch`, and a doctor warning when the model is missing. Real-model tests carry a new `model` marker, off by default.
2. Self-dedupe:
   - Store the voiced script's embedding in `renders.script_embedding`.
   - Compare it with the latest render of each of the identity's last 50 other briefs whose posts reached `qa_held` or later. Failed and rejected posts never went out, so they don't count.
   - A cosine above the limit is a fail that names the brief and the score.
3. Spec:
   - `measure_text_box()` in the render path, stored as `report.captions.box`.
   - `spec_check()` covers:
     - resolution and fps against `render:`;
     - duration inside the format and matching the plan within 0.2 s;
     - loudness within the tolerance, with true peak at most the target;
     - coverage at least the minimum when there is speech;
     - the caption box inside every target platform's safe zone.
   - A silent mix fails, except when the voice provider is a fake that is silent by design.
   - Captions narrow to fit: default and look maximum width 800.
4. Review: `QAReviewSubmission.adds` (voiceover, script, visuals, education) and `fits_identity`. A pass needs at least two adds and a fit. `get_render_report` shows the difference note. The prompt and the dry-run director are updated.
5. ADR 0018; golden frames looked at and refreshed after the caption width change; verify; record.

## Review Focus

1. A near-copy of an earlier script must fail even when reworded slightly → `test_a_reworded_script_fails_self_dedupe` (real model, `model` marker) and `test_a_copied_script_fails_self_dedupe` (fake).
2. Scripts from failed or rejected posts must not block a new post → `test_failed_posts_do_not_count_for_self_dedupe`.
3. Captions under the right-hand button rail must fail → `test_captions_under_the_button_rail_fail`.
4. A real mix that measures as silence must fail, not pass as "unmeasured" → `test_a_silent_mix_fails_unless_the_voice_is_a_silent_fake`.
5. A reviewer pass without two GR-3 additions must be refused → `test_a_pass_needs_two_additions`.
