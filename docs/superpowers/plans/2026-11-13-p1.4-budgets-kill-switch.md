# P1.4 Budget Ledger, Preflights, Caps and the Manual Kill Switch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution for this slice is native.

**Goal:** NFR-4 and the manual half of GR-7.
- **Every paid vendor has a monthly cap in `budget_ledger`:**
  - Claude: per-run `max_budget_usd`, never more than what is left of the monthly cap;
  - ElevenLabs: already capped, D10 and C16;
  - HeyGen: new, avatar credits.
- **Preflights:** a preflight runs before every voice, avatar and render batch. Each is a hard stop at the cap, reported in the digest and by toast.
- **Commands:**
  - `ce kill <identity>|--all` sets the kill flag and drops the identity to L0;
  - `ce warn <identity> "<text>"` records a platform warning and kills;
  - `ce resume <identity>` clears the flag and restores the YAML level.

**Architecture:**
- `engine/ops/budget.py` holds the pure ledger functions:
  - Claude run budget and run record;
  - HeyGen credit estimate, record and preflight;
  - disk preflight;
  - `budget_lines()` for the digest and `budget_status`.
- H3 calls those preflights.
- `engine/ops/killswitch.py` holds `kill`, `warn` and `resume`, logged in a new `identity_events` table (migration 0003).
- The CLI commands are thin wrappers over those functions.

**Spec:** `docs/SRD.md` NFR-4, §3.5, D10, C16, GR-7, §17, §2.3 (`ce kill`, `ce warn`, `ce resume`), §13 digest.

## Global Constraints

- Caps come from `engine.yaml`:
  - Claude: daily 3, weekly 5, monthly 60;
  - ElevenLabs: 78,600 characters, with a 20,000 floor;
  - HeyGen: new, `monthly_credit_cap` and `credits_per_minute`. These are placeholders until G0.5 shows Abbas's plan.
- Ledger charges are idempotent by `charge_key` (NFR-1): a retried tool never charges twice.
- Only Abbas raises autonomy (§17). A kill drops the identity to L0 in the database until `ce resume`, and syncing from YAML never lifts that.
- The engine does not touch Postiz on a kill. It lists the identity's drafted and scheduled posts so Abbas can pull them.

## Tasks

1. Budget module and caps:
   - `claude_run_budget(conn, config, month, command)` returns the smaller of the command budget and what is left of the month, and raises `BudgetStop` when nothing is left. `build_options` uses it.
   - `record_claude_run(conn, run_id, month, cost_usd, model_usage, turns, subtype)` fills `agent_runs` and adds a ledger row keyed `claude:run:<run_id>`.
   - HeyGen: credits estimated from the voiced audio length, recorded when an avatar is requested (`avatar:script:<id>`), and preflighted in H3.
   - Render: H3 also refuses when free disk is below `disk.stop_free_gb` (NFR-5).
   - `budget_status` and the digest read `budget_lines()`.
2. Kill switch:
   - migration 0003 adds `identity_events`;
   - `kill`, `warn` and `resume`;
   - `sync_identities` keeps a killed identity at L0;
   - the CLI commands, which print the in-flight posts.
3. Digest: an "Alerts" section listing paused identities and budget stops. Alerts count toward the toast.
4. ADR 0019; verify; record.

## Review Focus

1. A retried avatar request or a resumed run must not charge twice → `test_avatar_credits_are_charged_once_per_script` and `test_a_run_is_recorded_once`.
2. The last dollars of the month must cap the run budget, not just the daily figure → `test_the_run_budget_never_exceeds_what_is_left`.
3. A YAML sync after a kill must not restore L1 → `test_sync_keeps_a_killed_identity_at_l0`.
4. A kill on an unknown identity must fail loudly, not create a row → `test_kill_refuses_an_unknown_identity`.
5. A budget stop must reach Abbas even when nothing else waits → `test_a_budget_stop_alone_raises_the_toast`.
