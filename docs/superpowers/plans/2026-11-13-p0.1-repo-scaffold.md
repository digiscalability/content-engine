# P0.1 Repo Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution for this slice is native (the build prompt runs one slice per session in one session).

**Goal:** A uv Python project with ruff, pytest, a pre-commit secret scan, `ce doctor`, the repo docs (CLAUDE.md, README, PROGRESS, ADRs), `.env.example` and the config skeleton, so every later slice has somewhere to land.

**Architecture:** One package `engine/` at the repo root (SRD §5.7). `engine/settings.py` loads vendor keys from `.env` into an object, never into `os.environ`. `engine/doctor.py` runs checks through an injectable `Probes` object so tests use fakes (NFR-8). `scripts/check_secrets.py` is stdlib-only so the git hook runs with any Python.

**Tech Stack:** Python 3.11, uv (build backend `uv_build`), Typer, PyYAML, python-dotenv, pydantic (SecretStr), pytest, ruff.

**Spec:** `docs/SRD.md` (§18.2 P0.1; also §2.3, §3.4, §5.2, §5.7, §12, §14, §15, §19). Build rules: `docs/BUILD_PROMPT.md`.

**Requirement ids touched:** §5.2 (`ce doctor`, global `--dry-run`/`--identity`), §3.4, §12 (key names), NFR-5 (disk thresholds), NFR-7 (pre-commit secret scan), NFR-8 (fakes, markers `golden`/`gpu`/`live`), NFR-9 (no personal data or keys in the repo), FR-AGT-1 (settings half: keys never enter `os.environ`; the SDK env test lands in P0.7), GR-4 and GR-9 (CLAUDE.md "never" list), C6 (secret-scan convention from ventures-ops).

## Global Constraints

- Python `>=3.11`; uv; ruff; pytest markers `golden`, `gpu`, `live`, excluded from the default run (NFR-8).
- `.env` is gitignored; `.env.example` holds names only, never values (§3.4).
- Key names, in order (§12): `ANTHROPIC_API_KEY`, `ELEVENLABS_API_KEY`, `HEYGEN_API_KEY` (optional), `POSTIZ_API_KEY`, `PEXELS_API_KEY`, `YOUTUBE_DATA_API_KEY` (Phase 2), `REDDIT_CLIENT_ID` (Phase 2), `REDDIT_CLIENT_SECRET` (Phase 2).
- `ce doctor` "checks tools on PATH, GPU, disk, and which `.env` keys are **set or missing**, never printing a value" (§5.2).
- Disk: "warn below 60 GB free; stop ingest and indexing below 40 GB" (NFR-5).
- HyperFrames needs Node 22+ (§7.2).
- `engine.yaml` start values (§12, §5.3, §6.7, FR-PRD-5): model `claude-opus-5-5` for every agent; effort/max turns per §5.3 table; `max_budget_usd` daily 3, weekly 5; monthly Claude cap 60; ElevenLabs cap 78,600 chars, floor 20,000; loudness −14 LUFS, −1 dBTP; QA cross-identity frame 0.80 / script 0.85 over 180 days; self-dedupe 0.90 over 50 posts; caption coverage 0.95.
- ADR numbers 0001 (P0.3 HyperFrames spike) and 0002 (P0.6 Postiz findings) are reserved by the SRD; P0.1 ADRs start at 0003.
- Commits: branch `feat/p0.1-repo-scaffold` cut from `main`, Conventional Commits, stage files by name, never push.
- Doctor output is ASCII only (PowerShell 5.1 console codepage).

## Review Focus

1. A value pasted into `.env.example` (`PEXELS_API_KEY=abc…`, unquoted) is blocked by the scan; empty `NAME=` lines pass. → Task 1 test `test_filled_env_example_is_blocked`.
2. Staged files with non-ASCII names (the vault's `HOW WE WORK — …` style) are still scanned. → Task 2 test `test_hook_scans_non_ascii_file_names`.
3. Staged binaries (mp4/png fixtures from later slices) are skipped without crashing the hook. → Task 1 test `test_binary_text_is_skipped`.
4. `.env` values containing `=`, quotes or only spaces: set/missing is right and the value never prints. → Task 3 test `test_odd_values`.
5. A probe that exists but errors (nvidia-smi with no driver, ffmpeg returning non-zero) gives a warn or fail line, never a traceback. → Task 4 test `test_failing_probe_is_reported_not_raised`.

**Interfaces:**
- Produces (`scripts/check_secrets.py`, stdlib only):
  - `PATTERNS: list[tuple[str, re.Pattern[str]]]` — ventures-ops patterns plus `ElevenLabs key` `sk_[0-9a-f]{48}` and `Dotenv assignment` `^\s*(?:export\s+)?[A-Z][A-Z0-9_]*(?:KEY|SECRET|TOKEN|PASSWORD|ID)[A-Z0-9_]*\s*=\s*["']?([^\s"'#]{16,})`.   - `main(argv: list[str] | None = None) -> int` — `--staged` reads `git -c core.quotepath=false diff --cached --name-only -z --diff-filter=ACMR` and `git show :<path>`; else reads files. Prints `Secret scan blocked this commit:` plus findings to stderr; returns 1 if findings else 0.

### Task 4: doctor checks and `config/engine.yaml`

**Files:**
- Create: `engine/doctor.py`, `config/engine.yaml`, `tests/unit/test_doctor.py`

**Interfaces:**
- Consumes: `Settings`, `KEY_SPECS`, `REPO_ROOT` (Task 3).
- Produces (`engine/doctor.py`):
  - `Status = Literal["ok", "warn", "fail"]`; `@dataclass(frozen=True) class Check: group: str; name: str; status: Status; detail: str`
  - `@dataclass(frozen=True) class Probes: which: Callable[[str], str | None]; run: Callable[[list[str]], tuple[int, str]]; disk_free_bytes: Callable[[Path], int]` with `@classmethod real() -> Probes` (`shutil.which`, `subprocess.run` with timeout 15 s returning `(returncode, stdout+stderr)` and `(127, str(exc))` on `OSError`/timeout, `shutil.disk_usage(...).free`).

  - `run_checks(settings: Settings, probes: Probes, config: DoctorConfig, env_file_exists: bool, root: Path = REPO_ROOT) -> list[Check]`
  - `render(checks: list[Check]) -> str` (one line per check: `[ok  ] tools  ffmpeg  <detail>`), `exit_code(checks: list[Check]) -> int` (1 if any `fail`).

Disk on `root`: `< stop` fail, `< warn` warn, else ok with GB free. `.env` file present ok / absent warn (`copy .env.example to .env and fill it (Abbas)`). Keys: `ok` + `set` or `warn` + `missing (needed for <needed_for>)`. Missing keys never fail.
