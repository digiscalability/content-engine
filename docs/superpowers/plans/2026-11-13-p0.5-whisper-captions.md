# P0.5 Whisper Word Timings and HyperFrames Captions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution for this slice is native.

**Goal:** Word timings from faster-whisper large-v3 on CUDA (proved on the RTX 5070, FR-UND-1), grouped into caption groups and written as a HyperFrames captions composition that renders to an alpha overlay (FR-PRD-6); a caption fixture test proves the chain.

**Architecture:** `engine/library/transcribe.py` holds the `Transcriber` interface, `FasterWhisperTranscriber` (lazy model, injectable factory) and word alignment for tests. `engine/produce/captions.py` groups words (HyperFrames caption rules) and writes a project: a transparent root `index.html` hosting one `data-track-kind="captions"` sub-composition with every group, GSAP vendored. `render_ffmpeg` gains `mix_audio()` and `render(..., mix=)` so captions come from the **final mix** before the encode. The fixture is speech generated by Windows SAPI with its own word-boundary times as the reference (NFR-9).

**Tech Stack:** faster-whisper 1.2.1 / CTranslate2 4.9.0 (CUDA, bundled cuDNN 9), Whisper large-v3 (Systran CT2 conversion, ~3.1 GB, download approved by Abbas 2026-11-13), Windows `System.Speech`, HyperFrames 0.9.40.

**Spec:** `docs/SRD.md` FR-UND-1, FR-PRD-6, FR-QA-4 (coverage, measured here, enforced in P1.3), NFR-6 (VRAM < 11 GB), NFR-8, NFR-9, §7.2.

**Requirement ids touched:** FR-UND-1 (large-v3 on CUDA, word timestamps, language detect; fallback and ADR only if CTranslate2 fails on Blackwell; accept: word timings within 0.1 s of the reference), FR-PRD-6 (Whisper on the final mix → HyperFrames caption block), FR-QA-4 (caption coverage function, ≥ 95% on the fixture), NFR-6 (VRAM measured), NFR-8 (transcriber and model factory injectable; GPU work under the `gpu` marker), NFR-9.

## Global Constraints

- Model `large-v3`, `device="cuda"`, `compute_type="float16"`, `word_timestamps=True`, language detected (not forced); Hugging Face telemetry off (`HF_HUB_DISABLE_TELEMETRY=1`).
- Caption rules (HyperFrames `captions.md`): 3–5 words per group (default max 4), break at a sentence end, a pause ≥ 150 ms, or the word limit; one group on screen at a time; nothing before 0.1 s; portrait captions ~650 px from the bottom inside title-safe; match words by position, never by text.
- Captions composite after the LUT (ADR 0008) and render as ProRes 4444 alpha (ADR 0001).

## Review Focus

1. Whisper spells or punctuates differently from the script ("practise" vs "practice", "tomorrow." vs "tomorrow"): alignment must pair words by sequence, not exact text. → Task 2 `test_align_words_tolerates_spelling_and_punctuation`.
2. A word with a quote or `<` in it must not break the HTML. → Task 3 `test_words_are_html_escaped`.
3. Whisper hallucinates over silence and emits empty or `♪` tokens. → Task 3 `test_junk_tokens_dropped`.
4. Two groups must never overlap on screen, even when Whisper's word ends overrun the next word's start. → Task 3 `test_groups_never_overlap`.
5. A 1-word plan or a word at 0.0 s still produces a valid composition. → Task 3 `test_first_group_starts_no_earlier_than_0_1`.
