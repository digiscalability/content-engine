# P1.8 Job-Hunt Pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the repo hold its own job-hunt proof: CI on the pure modules, a 2–3 minute walkthrough rendered by the engine's own tools from a real dry run, a README and ADR index brought up to P0.6b.2, a scanned public-mirror tree, and a write-up draft for Abbas outside the repo.

**Architecture:** CI is one GitHub Actions job on `windows-latest` (the engine is Windows-only) that runs `uv sync --locked`, ruff, and `pytest` with every heavy marker excluded, including a new `media` marker for tests that need ffmpeg; a network tripwire in `tests/conftest.py` makes "no network" checkable. The walkthrough extends `scripts/make_demo.py`: it reads a dry run's database and files into plain facts, lays them out as timed chapters, renders them with the pinned HyperFrames, and cuts a short GIF teaser for the README. Nothing new enters `engine/`.

**Tech Stack:** Python 3.11, uv, pytest, ruff, GitHub Actions (`actions/checkout`, `astral-sh/setup-uv`, pinned by SHA), HyperFrames 0.9.40, ffmpeg.

**Spec:** `docs/SRD.md` §18.3 P1.8, §1.2 (job-hunt proof row), D1, D9, C11, NFR-7, NFR-8, NFR-9; `docs/adr/0014-showcase-and-public-mirror.md`; `docs/PROGRESS.md` › P1.8.

## Review Focus

- A test that shells out to ffmpeg but lacks the `media` marker turns CI red on a runner without ffmpeg: the local proof runs with ffmpeg off PATH (Task 1 Step 6).
- A brief or script containing `<`, `&` or `</template>` must not break or inject into the composition (Task 2 `test_card_text_is_escaped`).
- A dry run whose Short is longer than the chapter allows is trimmed, not overrun (Task 2 `test_the_short_chapter_is_capped`).
- A dry run with no metrics snapshot or no draft (QA held it) still builds; the after-draft card says what happened (Task 2 `test_facts_without_a_draft`).
- A registered marker missing from the CI expression would silently run heavy tests in CI (Task 1 `test_ci_excludes_every_registered_marker`).
