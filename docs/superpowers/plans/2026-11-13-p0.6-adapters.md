# P0.6 Vendor Adapters with Fakes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution for this slice is native.

**Goal:** Adapters for ElevenLabs (with the D10/C16 credit preflight and an idempotent ledger), HeyGen (API and drop folder behind one `AvatarProvider`) and the Postiz CLI (upload, channel settings, draft, status list), each with a fake, proved by contract tests that run the same assertions against the real adapter (on a mocked transport or runner) and the fake. ADR 0002 records how AI disclosure and post status work per channel.

**Architecture:** `engine/produce/voice.py`, `engine/produce/avatar.py`, `engine/publish/postiz.py`. HTTP adapters use `httpx` with an injectable transport (`httpx.MockTransport` in tests); the Postiz adapter runs the pinned CLI through `npx` with an injectable runner and sends posts as `--json` files. Contract tests live in `tests/contract/`. Nothing calls a vendor; `live` tests come with the live slices.

**Tech Stack:** httpx; ElevenLabs API v1 (`/v1/text-to-speech/{voice_id}?output_format=wav_48000`, `/v1/user/subscription`); HeyGen API v3 (`/v3/assets`, `/v3/videos`, `/v3/videos/{id}`); `postiz@2.0.27` CLI (public API v1 underneath).

**Spec:** `docs/SRD.md` FR-PRD-2, FR-PRD-3, FR-PUB-1–4, §3.5, §10, D10, C15, C16, NFR-1, NFR-4, NFR-8.

**Requirement ids touched:** FR-PRD-2 (TTS with clone and pronunciation dictionaries, WAV 48 kHz, characters to the ledger), FR-PRD-3 (HeyGen API and drop folder, request card, 48 h expiry, one contract test for both), FR-PUB-1 (upload first), FR-PUB-2 (read `integrations:settings`, refuse settings Postiz would drop; TikTok `DIRECT_POST`), FR-PUB-3 (YouTube private route; TikTok AI flag; Instagram none), FR-PUB-4 (drafts only), §10.4 (status from `posts:list`), D10/C16/NFR-4 (preflight: engine cap 78,600, account floor 20,000), NFR-1 (resumed batches never charge twice), NFR-8.

## Findings that shape the code (sources: vendor docs and Postiz source, 13 Nov 2026)

- ElevenLabs: `xi-api-key`; `wav_48000` output; up to 3 `pronunciation_dictionary_locators` (`pronunciation_dictionary_id`, `version_id`); no documented charge header, so the ledger records the characters sent; balance = `character_limit − character_count`.
- HeyGen v3: `POST /v3/assets` (multipart `file`, `x-api-key`) → `data.asset_id`; `POST /v3/videos` `{type: "avatar", avatar_id, audio_asset_id, aspect_ratio: "9:16", resolution: "1080p"}` → `video_id`; `GET /v3/videos/{id}` → `data.status` ∈ pending/processing/completed/failed, `video_url`, `failure_message`.
- Postiz: YouTube settings are `title`, `type` (public/private/unlisted), `selfDeclaredMadeForKids`, `thumbnail`, `tags`; no synthetic-content field, and its upload never sends YouTube's `containsSyntheticMedia`. TikTok has `video_made_with_ai` (sent as `is_aigc`, video and DIRECT_POST only). Instagram has no AI field. Post `state` ∈ QUEUE/PUBLISHED/ERROR/DRAFT; deleted posts drop out of `posts:list`. The CLI prints an emoji header line then JSON, reads `POSTIZ_API_KEY` from its environment, names uploads by the text after the last `/`, and on Windows is a `.cmd` shim.

## Global Constraints

- Keys come from `engine.settings.Settings` and reach only the one HTTP client or the Postiz subprocess env; errors never include a key.
- Drafts only (`type: "draft"`), `shortLink: false`; every media path comes from `upload`.
- Avatar files land at `media/inbox/avatar/<brief_id>.mp4`; a request waits at most 48 h.

## Review Focus

1. A run that crashed after ElevenLabs answered but before the ledger row was written must not pay again. → `test_resumed_batch_never_charges_twice`.
2. Settings Postiz would silently drop must stop the draft, not vanish. → `test_unknown_setting_is_refused`.
3. A Windows path with backslashes would reach Postiz as the file's name. → `test_upload_sends_a_forward_slash_path`.
4. A HeyGen job that fails reports why, and the drop folder expires after 48 h. → `test_failed_job_reports_the_reason`, `test_drop_folder_request_expires`.
5. A post Abbas deleted in Postiz disappears from `posts:list` and must read as `rejected`. → `test_engine_state_mapping`.
